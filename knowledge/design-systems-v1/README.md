# Design Systems Knowledge v1

Domínio profissional de **design** e frameworks CSS para a WLC.IA.

## Frameworks
- Tailwind CSS (utility-first, tema, componentes estilo shadcn)
- Bootstrap 5 (grid, componentes, admin/dashboard)
- Bulma (CSS-only, columns, hero/card)
- Pico.css (HTML semântico, mínimo elegante)

## Princípios
Harmonia, hierarquia, tokens, responsivo, a11y, checklist de entrega visual.

Ao gerar sites, a WLC.IA prioriza interfaces modernas, coerentes e profissionais —
escolhendo o framework adequado ao contexto, sem misturar stacks sem estratégia.
