# Game Studio Knowledge Domain v1.0.0

Especialização da WLC.IA em **criação de jogos web**, física/matemática de simulação, mecânica profissional e engenharia de plataforma — alinhada ao objetivo de competir com Replit, Lovable e Vercel, e de reconstruir/superar projetos no nível StreetRace.

## Módulo

- `src/lib/game-studio-knowledge.ts`
- Merge em `WLC_CORE_KNOWLEDGE` (versão `2.7.0-game-studio`)
- Boost de retrieval para intents de game studio / física de jogos / plataforma

## Domínios cobertos

| Domínio | Foco |
|---------|------|
| Game Studio | Fundamentos, cenas, economia, greenfield, comportamento da IA |
| Física de Jogos | Fixed-step, veículos, motor, draft, determinismo |
| Matemática de Jogos | Vetores, integração, BMEP/FMEP, transmissão |
| Engenharia de Jogos Web | Performance browser, autoridade server, data-driven |
| Mecânica Profissional | Preparação, diagnóstico, laudo |
| Plataforma de Desenvolvimento | Posicionamento vs Replit/Lovable/Vercel, agents, full-stack elite |

## Como a IA deve agir

1. **Criar jogo**: GDD curto → contrato de física → dados com origem → loop/cenas → economia → UI → backend → testes → deploy.  
2. **Melhorar projeto existente**: preservar invariantes corretas; não clonar cegamente; aumentar clareza, testes e rastreabilidade.  
3. **Física/mecânica**: unidades SI, hipóteses explícitas, DESCONHECIDO quando faltar evidência.  
4. **Plataforma**: planos aprováveis, sandbox real, completion honesto, secrets só no server.

## Relação com StreetRace

O domínio `StreetRace` continua com o conhecimento específico do paddock.  
O domínio **Game Studio** generaliza os princípios para qualquer jogo de simulação/web e orienta a construir **melhor**, não só igual.
